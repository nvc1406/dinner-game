# DinnerReady

Play the game: https://nvc1406.github.io/dinner-game/

This repository contains the Godot Web release build. GitHub Pages publishes the
`master` branch from the repository root. Keep all `index.*` files together and
keep `.nojekyll` when replacing the build.

To update the game, export the Web preset in the DinnerReady source project with
Web Content Export enabled and Thread Support disabled, replace the exported
files in this repository, and push to `master`.
